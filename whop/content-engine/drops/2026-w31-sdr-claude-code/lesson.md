**Objetivo:** montar un SDR digital con Claude Code que investigue cuentas, redacte el primer mensaje y deje el lead listo en el CRM — a partir de un flujo que ya haces a mano.

Esta semana no te llevas teoría de prospección. Te llevas **el agente**.

### Lo que verás en el vídeo (15 min)

- El flujo real de outbound que automatizamos, tal cual salió de un cliente.
- Cómo Claude Code lee una lista de cuentas y genera investigación + primer mensaje personalizado.
- Dónde conecta con el CRM para que el lead entre solo, con su contexto.
- Los límites: qué NO conviene automatizar todavía (y por qué).

### El activo

- **Template · prompt maestro del SDR** — el prompt que hace el trabajo, listo para pegar y adaptar a tu oferta.
- **Repo del agente** — el código para correrlo sobre tu propia lista.
