# qualivo-core · Núcleo documental

De aquí deriva todo lo demás: web, pitch comercial, guion de reuniones,
contenido, outbound, propuestas, ICPs y catálogo de agentes.
Si un material publicado contradice estos documentos, se corrige el material.

| Documento | Qué es | Cuándo usarlo |
|---|---|---|
| [`01-manifiesto.md`](01-manifiesto.md) | Quiénes somos y qué creemos | Web "sobre nosotros", contenido de marca, onboarding de equipo, contexto para agentes |
| [`02-prompt-ofertas-hormozi.md`](02-prompt-ofertas-hormozi.md) | Prompt reutilizable para diagnosticar y reconstruir cualquier propuesta de valor | Antes de lanzar una oferta, propia o de cliente |
| [`03-oferta-qualivo.md`](03-oferta-qualivo.md) | La oferta de Qualivo sometida a la Ecuación de Valor: nicho, promesa, bonos, garantía, precio y test | Landing, propuesta comercial, guion de llamada, outbound |

## Cómo se relacionan

El manifiesto convence a quien ya está interesado. La oferta es la que hace que
compre. No se sustituyen: el manifiesto es el trasfondo, la oferta es lo que se
pone encima de la mesa.

## Regla de mantenimiento

El documento 03 contiene supuestos declarados y huecos marcados `[dato EAC]`.
Ninguna cifra de resultado es un caso real hasta que se sustituya por una métrica
verificada. No se publica material comercial con esos huecos sin rellenar.

## Aplicarlo a un cliente

Copia el prompt de `02`, pásale la propuesta de valor del cliente tal cual la ve
su comprador, y guarda el resultado junto al original para poder comparar
versiones.
